# 369

This repository includes a simple command-line implementation of the game **Othello** (also known as Reversi). The game is written in Python and can be played locally.

## Requirements

- Python 3.7 or higher

## How to Run

Execute the following command from the repository root:

```bash
python othello.py
```

During the game, you will be prompted to enter moves in the format `row col`. Rows and columns are zero-indexed (from 0 to 7). Type `quit` or `exit` to abort the game.
